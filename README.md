# Quiz Dependência Celular

Um quiz educativo em formato PWA mobile-first sobre uso do celular, tempo de tela e bem-estar digital.

# Sobre o projeto

Este projeto foi criado para a exposição agropecuária de itapetinga - Bahia, 2026.

O quiz apresenta 8 perguntas rápidas e, ao final, mostra um dos três possíveis resultados:

- Uso equilibrado
- Sinal de alerta
- Dependência digital em potencial

# Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Manifesto PWA
- Service Worker

# Como usar

Abra o projeto em um navegador ou instale em um celular/tablet usando a opção **“Adicionar à tela inicial”**.

No Android, abra pelo Chrome e toque em:

```⋮ Menu → Adicionar à tela inicial```

No iPad/iPhone, abra pelo Safari e toque em:

```Compartilhar → Adicionar à Tela de Início```
